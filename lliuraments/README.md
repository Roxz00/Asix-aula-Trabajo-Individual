# Entregas

PDF de entrega de cada tarea de la parte individual, generados a partir de los documentos de [docs/](../docs/) con
[scripts/generar-lliurament.py](../scripts/generar-lliurament.py):

```bash
python3 scripts/generar-lliurament.py 0 2 4     # o «todas»
```

Cada PDF lleva una portada con el enlace al repositorio y dónde está la tarea, y después el documento completo.
